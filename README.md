# About me

Hi :wave: I'm Oscar. I love working on hard technical problems, and always
enjoy learning new things that help me get better at this.

## Work preferences

Here are the main things to know about how I work:

- I will always try to get back to you as soon as possible. When I can't respond to you
immediately I will let you know that I have seen your message. If I acknowledge your message
I _will_ respond once I have gathered my thoughts, and I've made sure that I understand the
topic enough to meaningfully contribute.
- I value context, and appreciate it when as much of it is added as possible.
- I like to write things down. Throughout my remote work career, I have really
learned to appreciate the power of writing something down. Relating this to the
point above, I value written context highly.
- I heavily use a stacked diffs workflow, and I almost exclusively use `jj` to
work with Git repos. You'll likely see random looking branches in my PRs as a result.
I'm not attached branch naming conventions. If you'd prefer a human readable name
let me know.

I'm very open to adapting how I do things, so please let me know if you have
differing preferences, or if you have any advice to share on how I could do
something better. I truly mean it when I say I love learning new things, so
please send feedback and advice my way!
