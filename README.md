# About me

Hi :wave: I'm Oscar. I love working on hard technical problems, and always
enjoy learning new things that help me get better at this.

## Work preferences

Here are the main things to know about how I work:

- I will always try to get back to you as soon as possible. When I can't respond to you
immediately I will let you know that I have seen your message. If I acknowledge your message
I _will_ respond once I feel confident that I can meaningfully contribute.
- I value context, and appreciate it when as much of it is added as possible.
- I like to write things down. Having a written and easy to find record has a lot
of benefits like historical analysis and conducivity to deep though.
- I heavily use a stacked diffs workflow, and I almost exclusively use `jj` to
work with Git repos.

I'm open to adapting how I do things, so let me know if you have
differing preferences, or if you have tips on how I could do something
better.
